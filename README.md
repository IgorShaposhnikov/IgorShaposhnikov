# Hey, I'm Igor 👋

I'm a **C#/.NET developer**. I'm currently working on **Cvolo**, **SRTLab**, and **Lexplosion**, while also contributing to open-source projects in the .NET ecosystem.

### What I'm building

**🦅 [Cvolo](https://github.com/IgorShaposhnikov/Cvolo)** — an experimental compiled programming language with C#-inspired syntax and an LLVM backend. I'm developing the compiler, including type analysis, ownership, borrowing, and reference lifetime checks, as well as the tools around the language.

[Compiler](https://github.com/IgorShaposhnikov/Cvolo) · [Language Server](https://github.com/CvoloLang/lsp-cvolo) · [VS Code extension](https://github.com/CvoloLang/vscode-cvolo) · [Book / documentation](https://github.com/CvoloLang/book)

**🔬 SRTLab** — a platform for remotely working with physical IoT laboratory benches. It uses a modular ASP.NET Core backend, MQTT for device communication, WebRTC for video streaming, Svelte frontends, and .NET Aspire for local orchestration. The source code is currently private.

**🎮 [Lexplosion](https://github.com/NightWorldTeam/Lexplosion)** — a Minecraft launcher developed with the NightWorldTeam. My work includes WPF UI, client-side features, and modernization of the existing application. I'm also exploring how to separate presentation logic from WPF-specific views to make it reusable across UI frameworks.

### Open source

**📖 [MarkdownWPF](https://github.com/IgorShaposhnikov/MarkdownWPF)** — a Markdown renderer built on Markdig that uses virtualized WPF elements rather than `FlowDocument`. It supports custom XAML styles, images, and optional HTML rendering.

**🧩 [CommunityToolkit.Aspire — Mosquitto](https://github.com/CommunityToolkit/Aspire/pull/1520)** — a merged contribution adding Eclipse Mosquitto hosting support to Aspire, including resource configuration, MQTT health checks, persistence options, examples, and tests.
